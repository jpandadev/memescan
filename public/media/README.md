# Media Assets

This folder contains all branding and media assets for MemeScan.

## Structure

```
media/
├── branding/          # Logos, wordmarks, brand guidelines
│   ├── logo.svg       # Primary logo (vector)
│   ├── logo.png       # Primary logo (raster)
│   ├── wordmark.svg   # Text logo
│   └── colors.md      # Brand colors
│
├── og/                # Open Graph images (social sharing)
│   ├── memescan-og.png       # Default OG image (1200x630)
│   ├── cryptokart-og.png     # CryptoKart OG image
│   └── rewards-og.png        # Rewards page OG
│
├── icons/             # Favicons and app icons
│   ├── favicon.ico           # Browser favicon
│   ├── favicon-16x16.png
│   ├── favicon-32x32.png
│   ├── favicon-192x192.png   # Android
│   ├── apple-touch-icon.png  # iOS (180x180)
│   └── safari-pinned-tab.svg
│
└── decks/             # Pitch decks and presentations
    └── (drop your PDFs here)
```

## Image Sizes

| Type | Size | Format |
|------|------|--------|
| OG Image | 1200x630 | PNG |
| Twitter Card | 1200x600 | PNG |
| Favicon | 16x16, 32x32 | ICO/PNG |
| App Icon | 192x192, 512x512 | PNG |
| Apple Touch | 180x180 | PNG |

## Brand Colors

- Primary: `#00FF88` (MemeScan Green)
- Background: `#0a1a0a` (Deep Matrix)
- Accent: `#FF6B35` (CryptoKart Orange)
- Danger: `#FF4444` (Rug Alert Red)

- Use dark backgrounds for consistency with the app
